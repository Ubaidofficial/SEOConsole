No referring sitemaps detected

URL Inspection did not find this URL in any sitemap that Google has processed for the property. On its own it is not an error: Google finds most pages through links as well. It is worth a look when the page is important and also not indexed.

Updated 28 November 2026 · Search Console guide

On this page

  1. What the message means
  2. When it is only timing
  3. When it points to a real gap
  4. How to fix it

What the message means

In URL Inspection, under how Google discovered the page, the sitemaps section lists sitemaps that include the URL. "No referring sitemaps detected" means none was found for this exact URL. Pages can still be crawled and indexed without one.

When it is only timing

  • The URL is new and Google has not processed the latest version of your sitemap yet.
  • Google crawled the page before it processed the sitemap that lists it.
  • The URL is unknown to Google so far, so there is nothing to show.

Check the Sitemaps report: if the sitemap shows Success and a recent "last read" date, wait for the next crawl.

When it points to a real gap

  • The URL in the sitemap differs from the one inspected: http vs https, www. vs bare domain, a trailing slash, or parameters.
  • The page is missing from the sitemap: a plugin excludes a post type, or a static sitemap was never updated.
  • The sitemap is not in this property: submitted under a different property, or never submitted and not listed in robots.txt.
  • The sitemap has a problem; see Sitemap could not be read.

How to fix it

  1. Make sure the sitemap lists the canonical URL exactly as Google should index it.
  2. Submit the sitemap in the property, and list it in robots.txt with a Sitemap: line.
  3. Keep lastmod accurate so Google can tell which pages changed.

Related guides

  • Discovered – currently not indexed

    Google knows the URL exists but has not crawled it yet. Common on new sites, large sites and pages with few internal links.

  • Crawled – currently not indexed

    Google fetched the page and decided not to index it for now. Usually about how useful and distinct the page is.

  • Sitemap could not be read

    Search Console could not fetch or parse your sitemap. Check it loads for Googlebot, is valid XML and is not blocked.

  • Duplicate without user-selected canonical

    Google treats the page as a copy of another URL and picked that one to show, because you did not say which you prefer.
