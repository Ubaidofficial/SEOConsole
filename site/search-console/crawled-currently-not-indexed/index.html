Crawled – currently not indexed

Google fetched the page and decided not to add it to the index, at least for now. Google's help says it does not index every page on the web, so this is a common message for many sites and does not necessarily mean something is broken.

Updated 28 November 2026 · Search Console guide

On this page

  1. What the status means
  2. Decide whether it matters
  3. Common causes
  4. What helps

What the status means

In Indexing → Pages, this reason means Googlebot crawled the URL but Google chose not to index it. Unlike Discovered – currently not indexed, Google has seen the page, so the question is less about crawling and more about the page itself.

Google's advice is to use URL Inspection on important pages with this status to see if something on the site stops them from appearing. For tag archives, thin variants or old filter URLs, the status is often exactly what you would want.

Decide whether it matters

  • Ignore it for URLs you would not want in search anyway: internal search results, empty tag pages, parameter URLs, feeds.
  • Act on pages that should earn traffic: product pages, guides, landing pages, new posts that have sat here for weeks.

Common causes

  • Little of its own to offer: short pages, near-copies of other pages on the site, or pages that repeat what many other sites already say.
  • Weak internal signals: the page is linked from few places, or only from the sitemap.
  • Rendering problems: the main content only appears after JavaScript that fails for Googlebot. Check the rendered HTML and screenshot in URL Inspection's live test.
  • Too many similar URLs: a site that publishes many pages of the same kind, where Google indexes some and holds back the rest.

What helps

  1. Make the page clearly useful and distinct: answer the question fully, add first-hand detail, and merge near-duplicates into one stronger page.
  2. Link to it from relevant, already-indexed pages on your site.
  3. Check rendering in URL Inspection: the important text should be in the rendered HTML.
  4. Request indexing for a few improved key pages, then press Validate fix. Google's help says validation typically takes up to about two weeks, and sometimes much longer.

Resubmitting the same page unchanged rarely changes the outcome. Improve the page first, then ask again.

Related guides

  • Discovered – currently not indexed

    Google knows the URL exists but has not crawled it yet. Common on new sites, large sites and pages with few internal links.

  • Sitemap could not be read

    Search Console could not fetch or parse your sitemap. Check it loads for Googlebot, is valid XML and is not blocked.

  • No referring sitemaps detected

    URL Inspection found no processed sitemap that lists this URL. Often only timing, sometimes a URL that differs from the one in the sitemap.

  • Duplicate without user-selected canonical

    Google treats the page as a copy of another URL and picked that one to show, because you did not say which you prefer.
