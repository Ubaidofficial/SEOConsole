Page with redirect

The URL redirects to another page, so Google does not index it. Google's help describes it as a non-canonical URL that redirects; whether the target is indexed depends on what Google thinks of the target. Most of the time this entry is expected.

Updated 28 November 2026 · Search Console guide

On this page

  1. What the status means
  2. When it is normal
  3. When it is a problem
  4. How to clean it up

What the status means

A redirecting URL is never indexed itself: Google follows it and evaluates the destination. So this reason only says Google found URLs that redirect. Check the destination separately with URL Inspection if you care about it.

When it is normal

  • http:// to https://, and www. to the bare domain or the other way round.
  • Old URLs redirected after a redesign, a migration or a merged article.
  • Trailing-slash or case normalisation, such as /pricing to /pricing/.

When it is a problem

  • Your sitemap lists redirecting URLs. A sitemap should list final, canonical URLs that return 200.
  • Internal links point at redirects, adding a hop on every click and every crawl.
  • Redirect chains: A → B → C. Point A straight at C.
  • A page that should rank redirects by mistake, for example a rule that is broader than intended. Google lists broken chains, loops and bad targets separately, as Redirect error.

How to clean it up

  1. Export the example URLs from the report and check where each one ends up.
  2. Replace redirecting URLs in the sitemap with their final URLs.
  3. Update internal links, menus and canonical tags to the final URLs.
  4. Collapse chains into single redirects, and keep permanent moves as 301 or 308.

Related guides

  • Duplicate without user-selected canonical

    Google treats the page as a copy of another URL and picked that one to show, because you did not say which you prefer.

  • Alternate page with proper canonical tag

    The page points to another URL as its canonical and Google agreed. Usually fine, unless the tag points somewhere it should not.

  • Discovered – currently not indexed

    Google knows the URL exists but has not crawled it yet. Common on new sites, large sites and pages with few internal links.

  • Crawled – currently not indexed

    Google fetched the page and decided not to index it for now. Usually about how useful and distinct the page is.
