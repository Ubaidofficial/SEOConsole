IndexNow

IndexNow is an open protocol that lets a website tell search engines the moment a URL is added, changed or removed, instead of waiting to be crawled. Bing and several other engines take part. Google does not, so it is a complement to your sitemap, not a replacement.

Which engines use it

Bing, Yandex, Naver, Seznam and Yep take IndexNow submissions, and participating engines share what they receive with each other. Google does not use IndexNow: for Google, keep an accurate sitemap and use Search Console.

How it works

  1. You create a key, a random string of letters, digits and dashes.
  2. You put a text file named after the key at your site's root, containing just the key, for example https://example.com/0123456789abcdef.txt. That proves you control the site.
  3. When a URL changes, you send it with the key. The engine checks the key file and queues the URL for crawling.

Set it up

  1. Generate a key: Bing Webmaster Tools can make one, or use any random string of letters, digits and dashes (the IndexNow documentation allows 8 to 128 characters).
  2. Upload <key>.txt to the root of the host whose URLs you will submit. Each host, such as www. and the bare domain, needs the file.
  3. Check it loads publicly as plain text, with nothing but the key.

Submit URLs

One URL:

https://api.indexnow.org/indexnow?url=https://example.com/new-page/&key=0123456789abcdef

Many URLs at once, as a JSON POST:

POST https://api.indexnow.org/indexnow
Content-Type: application/json; charset=utf-8

{
  "host": "example.com",
  "key": "0123456789abcdef",
  "keyLocation": "https://example.com/0123456789abcdef.txt",
  "urlList": ["https://example.com/a/", "https://example.com/b/"]
}

A 200 or 202 answer means the engine received the list. It does not mean the pages are indexed.

Good practice

  • Send URLs when they are added, changed or removed, not on every deploy, and do not resend unchanged pages.
  • Only send URLs on the host the key belongs to.
  • Keep your sitemap too: IndexNow tells engines what changed, the sitemap tells them what exists.

IndexNow in SEOConsole
