Best Claude plugins and MCP servers for SEO

Claude does SEO work well when it can see real data: your Search Console clicks, your analytics, a keyword database. These are the plugins and connectors that give it that data, what each one is good at, and what it needs. We make SEOConsole, the first entry, so read that one with that in mind; the rest are listed for what they do.

Updated 28 November 2026. Products change quickly; check each vendor's own page before you rely on a detail.

Plugins, skills and MCP connectors

  • MCP connectors (Model Context Protocol) give Claude live tools and data, such as "read my Search Console clicks". In Claude you add them as custom connectors; in Claude Code with claude mcp add.
  • Skills and plugins give Claude a method: instructions and commands for a task such as an SEO audit. Plugins can bundle skills, commands and MCP connectors together.

The best setup is usually one of each: a data source, and a method that knows what to do with it.

Ahrefs and Semrush offer their own MCP servers, and Google has released one for Google Analytics. For Search Console, industry reviews we read found no official Google MCP server; every option, including ours, is third-party.

Which to pick

  • You run several sites and want answers from your own data: SEOConsole MCP, plus the Marketing plugin's /seo-audit for a structured plan.
  • You need keyword volumes and competitor data: Ahrefs or Semrush MCP, whichever you already pay for.
  • You only need analytics questions answered: Google's Analytics MCP.
  • You want hosted Search Console analysis and do not want to run a server: a hosted option such as GSC Wizard.

How to add one to Claude

A connector in Claude

  1. Open Settings → Connectors and choose Add custom connector.
  2. Paste the server's MCP address, then Connect and sign in.

A plugin in Claude Code

/plugin marketplace add anthropics/knowledge-work-plugins

Then install the Marketing plugin from that marketplace. For an MCP server, use claude mcp add --transport http <name> <address>; the SEOConsole MCP page has the exact command.
